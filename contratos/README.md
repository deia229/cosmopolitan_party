# Contratos - Apps Script

## Ficheiros

- **Contratos_v3.gs** - Geração de contratos em PDF
- **Festas.gs** - Backend do dashboard CRM

## Deploy

1. Ir a [script.google.com](https://script.google.com)
2. Criar novo projeto
3. Copiar conteúdo dos ficheiros .gs
4. Configurar trigger para `doGetDashboard`
5. Deploy como Web App

## Configuração

Ver `docs/deploy-guide.md` para instruções completas.
