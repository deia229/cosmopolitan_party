# 🎉 Cosmopolitan Party

Sistema completo de gestão operacional para espaço de eventos.

## 📦 Componentes

- **Dashboard CRM** - Interface web (Netlify)
- **Contratos** - Geração automática (Apps Script)
- **Checklist Custos** - Ferramenta offline para iPad
- **Documentação** - Guias de deploy e referência

## 🚀 Quick Start

```bash
# Deploy do dashboard
cd dashboard
netlify deploy --prod

# Apps Script
Copiar ficheiros de contratos/ para script.google.com

# Checklist
Abrir checklists/cp_checklist_custos.html no iPad
```
